# Superlocal source

This repository contains Brady Moore's personal customization of [R44VC0RP/superlocal](https://github.com/R44VC0RP/superlocal), based on commit `65a55e89eda1080213d5b625ac62d339ff1d2be4`.

The source was recovered from the current installed Superlocal app, including its React UI, local host, inbox SDK, assets, and personal UI changes. The Objective-C wrapper, light appearance configuration, and app icon are included in `native/`; the PNG icon is in `assets/`.

The upstream snapshot does not contain a top-level license file. This import does not apply the earlier Swift project's MIT license to upstream Superlocal code or assets. Existing upstream notices remain in their source files.

The earlier Swift app remains in this repository's Git history before the Superlocal import. Its existing release belongs to that earlier version.
