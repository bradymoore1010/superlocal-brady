# Support

Mail is a personal open-source project rather than a commercial email service.

- Use [GitHub Issues](https://github.com/bradymoore1010/mail/issues) for reproducible bugs and focused feature requests.
- Use [GitHub Discussions](https://github.com/bradymoore1010/mail/discussions) for setup questions and broader product ideas once Discussions is enabled.
- Use private vulnerability reporting for security problems.

Before posting, remove real names, email addresses, subjects, body text, OAuth values, local database paths, and screenshots from your Gmail account. A fictional reproduction is the fastest path to a useful answer.
