# Mail keyboard shortcuts

## Navigation and mailboxes

| Keys | Action |
| --- | --- |
| `J` / `K` | Next or previous conversation |
| `Return` | Open selected conversation or chosen command |
| `Esc` | Close the current layer or return to inbox |
| `G`, then `I` | Go to Inbox |
| `G`, then `S` | Go to Starred |
| `G`, then `T` | Go to Sent |
| `G`, then `D` | Go to Drafts |
| `G`, then `A` | Go to Archive |

## Search and commands

| Keys | Action |
| --- | --- |
| `⌘K` | Search all mail or run a command |
| `/` or `⌘F` | Search the current mailbox |
| `↑` / `↓` | Move through command results or recipient suggestions |
| `Tab` | Complete the active recipient suggestion |

## Message actions

| Keys | Action |
| --- | --- |
| `E` | Archive and advance |
| `R` | Open or focus reply |
| `S` | Toggle star |
| `U` | Toggle read or unread |
| `C` | Compose |
| `⌘Return` | Send reply or composed message |
| `⌘Z` or `Ctrl-Z` | Undo the latest archive or send within five seconds |

## Writing and attachments

| Keys | Action |
| --- | --- |
| `⇧⌘A` | Attach files |
| `⇧⌘8` | Toggle a bulleted list |
| `⇧⌘7` | Toggle a numbered list |
| `⌘[` / `⌘]` | Decrease or increase indentation |
| `Tab` / `Shift-Tab` | Indent or outdent the current list item |
| `⌘Backspace` | Delete to the start of the current line; press again on an empty line to remove the line above |

The native editor also honors standard macOS selection, clipboard, undo, link, and text-formatting commands.
